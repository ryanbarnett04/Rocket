# Rocket

- Rocket is a Static Analysis tool (and my Honours project) designed to parse code for violations of the Power of 10
- The Power of 10, written by Gerard J. Holzmann, provides a strict, concise set of coding rules designed to ensure the extreme reliability, safety, and verifiability of safety-critical software

## Technology
- The project is written in C++ and uses Clang Tooling to walk the generated AST's for rule violations
